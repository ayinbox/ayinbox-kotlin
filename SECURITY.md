# Security

Report a vulnerability in this library by email to team@ayinbox.com. Do not open a public issue for it.

Include the version, what you found and how to reproduce it. We will reply to confirm we received it.

Never include a real API key (`aybox_...`) or OAuth token (`ayat_...`) in a report. If one was exposed, revoke it in the dashboard at https://app.ayinbox.com.
